# Kondor extensions

Extensions for [Kondor](https://github.com/lukasborges/kondor), a KDE Plasma web browser.
A Kondor extension is a small package of page scripts and styles, an optional settings form
and an optional toolbar menu. It runs only where its permissions allow.

## Install an extension

- In Kondor, open **Settings → Extensions** and choose **Get New Extensions…**.
- Or download a `.kondorext` file from the [catalog page](https://lukasborges.github.io/kondor-extensions/)
  and choose **Install from File…** in the same page.

The catalog is published from this repository on every merge to `main`.
