# Dark Mode

## What it does

Shows every site with dark colors built from the page's own colors, so images and videos keep
their colors and there is no white flash while a page loads. Pages that are already dark are left
alone.

- Brightness, contrast and sepia settings change the colors of open tabs without a reload.
- "Only when the system uses a dark color scheme" makes it follow the system color scheme.
- "Dim Images" in the toolbar Extensions menu dims images and videos. It is remembered across tabs
  and restarts, and in a private tab it applies to that tab only.
- "Run on <site>" turns it off for a site.

## Permissions

- https://*/*: needed to darken every secure site.
- http://*/*: needed to darken every plain site.
- It asks for no API permission.

## Network
